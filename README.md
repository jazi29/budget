# Бюджет

Статический сайт без сборки и серверной части: `index.html`, `style.css`, `app.js`, иконки и `manifest.webmanifest`.
Данные хранятся в localStorage браузера пользователя.

## Деплой
Подойдёт любой статический хостинг, достаточно загрузить содержимое папки как есть:
- **Netlify**: app.netlify.com/drop, перетащить папку.
- **Cloudflare Pages / Vercel / GitHub Pages**: build command пустая, output directory `/` (корень).

## Важно
- localStorage привязан к домену. Записи из версии на claude.ai на новом домене не появятся сами: сначала нажмите «⋯» → «Скачать копию» в старой версии, потом на новом сайте «⋯» → «Загрузить из файла».
- Сайт нужно открывать по HTTPS (хостинги выше дают его по умолчанию).
- На iPhone: Safari → «Поделиться» → «На экран „Домой“».
- Валюта меняется в `app.js`: переменная `CUR`.

## Быстрое добавление по ссылке (для «Команд» iPhone)
Откройте сайт с параметрами, и операция добавится сама:

`https://ВАШ-САЙТ/?type=out&amount=5000&note=Magnum&id=УНИКАЛЬНЫЙ_НОМЕР`

- `type`: `out` (расход, по умолчанию) или `in` (доход)
- `amount`: сумма (символы валюты и пробелы игнорируются)
- `note`: заметка, по ней подбирается категория (или передайте `cat=Еда`)
- `date`: `ГГГГ-ММ-ДД` (по умолчанию сегодня)
- `id`: любой уникальный номер, защищает от дублей при повторном открытии
